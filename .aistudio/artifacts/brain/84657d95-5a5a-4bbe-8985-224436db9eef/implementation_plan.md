# 主图与详情页同源流转 · 印花4维主题联动与多角度产品编排升级计划

本计划旨在打通「1:1/3:4 主图套图」与「3:4/9:16 详情页分屏」的同源生产链路，解决卡通印花多款式产品“场景元素联动生硬、底部胶囊配色死板、多角度产品图无法组合调用、以及视觉规范提取空泛”四大核心痛点。

---

## 用户审阅与关键设计决策

> [!IMPORTANT]
> 以下为本次升级的核心架构与交互决策，审阅确认后即可点击「Proceed」一键落地实现：

- **决策 1：主图与详情页「同源套图 + 一键纵向延展」双轨流转**
  - 保留顶部「① 详情页工作台」与「② 主图/SKU复刻工作台」双入口，同时在主图工作台顶部与每张已生成的卡片上新增 **「一键延展为详情页 (3:4 / 9:16)」** 动作。
  - 支持两种转换模式：**① 成图基准纵向重构（推荐）**——直接将已生成的满意 `1:1` 主图成图 + 对应 `#Prod` 原图送入生图模型，保持产品、印花联动道具、配色与文案 100% 不变，仅将画幅上下纵向舒展为 `3:4` 或 `9:16` 详情屏；**② 同配方切比例重绘**——复用全套文案、多角度 `#Prod` 与印花联动配方直接按竖屏比例渲染，并可在详情页工作台一键追加「规格参数表 / 包装清单 / 售后保障」收尾屏，实时拼接为无缝详情长图。
- **决策 2：专为卡通/潮玩印花打造的「4维主题深度联动配方（Print Theme DNA）」**
  - 针对《太空芝士鼠》《美梦兔》《露营刺猬》等多印花款式，彻底告别“只换脚下两个生硬塑料摆件、背景和黑棕胶囊框一成不变”的浅层替换。
  - 新增 **「印花主题全维联动」** 模式：AI 自动识别 `#Prod` 壳面插画故事，在每张卡片上生成可视化的 **4 维联动配方条**（`① 主题色板`、`② 潮玩联动底座`、`③ 印花伴生悬浮元素`、`④ 标题与胶囊配色`），用户可在卡片上一眼审阅并随时手动微调。
- **决策 3：多角度 `#Prod` 产品素材智能视角打标与单卡多图组合绑定**
  - 突破原先单张复刻卡只能绑定 1 张 90° 正立面产品图的限制。支持为 `#Prod` 标注视角角色（`正面印花主视`、`开盖双耳`、`单耳特写`、`细节/充电`、`多款合集`），并在每张卡片上开放 **多角度 `#Prod` 自由多选胶囊**（如第 1 张 KV 卡同时绑定「正面印花仓 + 单只耳机特写」，第 5 张合集卡同时绑定「全部 5 款印花产品图」）。
- **决策 4：《整页统一视觉规范》升级为 6 大具象物理锚点（零套话高密度卡）**
  - 废除原先空泛的形容词套话，将竞品视觉规范严格锁定为 **180~220 字的 6 大物理锚点**：`① 60-30-10色彩配比与HEX色号（自动随我方#Prod校准主色相）`、`② 唯一主展台与辅件材质`、`③ 主光方位与色温阴影`、`④ 标题与正文层级色号`、`⑤ UI卡片/胶囊圆角与描边规范`、`⑥ 画布安全边距与三段式网格`。

## 1. 核心理念与业务价值

- **解决什么问题**：
  1. **消除主图与详情页的割裂感**：5~7 张高转化主图（首焦KV、全卖点Bento宫格、音质/降噪单卖点、续航/佩戴单卖点、多花色合集）本质上就是详情页的前 5~7 屏核心内容，通过同源卡片与比例重构，一次策划即可同时收获 `1:1` 主图与 `3:4 / 9:16` 详情长图。
  2. **让每一款印花真正“活”在自己的主题世界里**：从壳面插画（如露营刺猬的洋梨帐篷、太空鼠的芝士火箭、美梦兔的星月云朵）直接生长出同世界观的**盲盒级磨砂展台底座、远中近景伴生小元素、渐变背景色温以及专属胶囊/标题配色**。
  3. **还原同行大牌的多视角丰富度**：像联想、倍思案例一样，在不同模块卡片中灵活组合「开盖仓 + 合盖仓 + 单耳特写 + 多色矩阵」，告别全套图同一个正立面角度的单调感。

## 2. 用户体验与界面交互设计 (UX & Visual Design)

### A. 核心操作流（3 步闭环）

1. **步骤 1：上传素材与视角标识（左栏）**
   - 上传同行参考套图（`#Case`，如 5 张 `1:1` 或 `3:4` 卖点套图）与自家产品原图（`#Prod`，支持同款多角度或多款不同印花）。
   - 每张 `#Prod` 缩略图下方显示紧凑的视角角色切换器（`正面主视` · `开盖双耳` · `单耳特写` · `细节/配件` · `多色合集`），AI 排卡时也会根据图像内容自动校准角色。
2. **步骤 2：选择联动模式并一键 AI 排卡（左栏 ➔ 右栏卡片）**
   - 左侧「色彩与主题联动」提供 3 档直观分段切换：
     - `锁死原场景`（仅替换产品主体，保留参考图原背景与灯光）
     - `同色系顺应`（提取产品主色协调背景色温，适合纯色简约款）
     - `印花主题全维联动`（默认推荐：背景色 + 潮玩底座 + 印花伴生元素 + 标题/胶囊配色 4 维联动）
   - 点击 **「先排卡微调」** 后，AI 自动完成：
     - 识别每张 `#Case` 的版式骨架（首焦KV / Bento多卖点宫格 / 1拖2佩戴体验 / 续航功能场景 / 多色矩阵）；
     - 为每张卡片自动勾选最匹配的 **1~N 张多角度 `#Prod` 产品图**；
     - 为每张卡片生成可视化的 **「🎨 印花 4 维联动配方条」** 与 **「画面卖点文案」**。
3. **步骤 3：批量复刻出图 ➔ 一键延展为详情页长图（右栏工作区）**
   - 在每张卡片上可直接微调「主标题」「画面卖点文案」「印花4维联动胶囊」以及「绑定的多角度 `#Prod`」，点击「一键复刻全部」生成高清主图。
   - 主图生成完毕后，点击顶部 **「一键延展为详情页 (3:4 / 9:16)」**（或单卡上的 `转详情屏` 按钮），系统自动将这组主图卡片推送至详情页工作台并启动纵向画幅重构，支持一键追加规格表/包装清单屏并预览无缝长图。

### B. 卡片视觉与空间布局规范

- **色彩与表面层级**：延续工作台高对比度专业浅色画布（`#F4F5F7` 底色 + `#FFFFFF` 纯白单层卡片 + `1px solid #E2E8F0` 细边框），遵循 60-30-10 视觉配比，所有序号与尺寸参数统一采用等宽对齐数字（`tabular-nums`）。
- **卡片内「🎨 印花4维联动配方条」紧凑布局**：
  - 在复刻卡片的文案区下方，以清爽的 2×2 紧凑网格展示 4 个可编辑联动锚点输入框：
    - `主题色板`（如：`晨雾果绿 #EBF5EE + 洋梨暖黄 #FDE68A`）
    - `联动底座`（如：`潮玩圆润磨砂草坪与微缩露营台`）
    - `伴生元素`（如：`3D软萌洋梨、黄色小雏菊、暖光十字星点`）
    - `胶囊/字色`（如：`深橄榄绿主标题 + 暖琥珀圆角数据胶囊`）
- **卡片内「多角度 `#Prod` 绑定栏」**：
  - 支持点击切换或同时点亮多张 `#Prod` 缩略图胶囊（带视角角色文字标识），并保留预览对比区（左侧展示绑定的 `#Case` 与多张 `#Prod` 缩略网格，右侧展示高清复刻结果图）。

## 3. 关键产品决策与技术取舍

- **决策 1：如何让 `1:1` 主图转化为 `3:4 / 9:16` 详情页分屏时既不变形、又不丢风格？**
  - *选定方案*：提供 **「基于已生成 1:1 成图的纵向重构（Image-to-Image Vertical Reframing）」** 作为首选模式，同时保留 **「同配方直接按新比例生图」** 选项。
  - *原因*：当用户已经抽出一张非常满意的 `1:1` 主图时，把这张 `1:1` 成图连同 `#Prod` 原图一起作为参考输入给生图模型，要求模型“锁死成图的配色、潮玩底座、伴生元素与产品外观，仅向顶部和底部延展纵向空间以容纳更舒展的标题区和卖点胶囊区”，能做到 **100% 跨画幅视觉零偏差**，且彻底杜绝商品被垂直拉长。
- **决策 2：如何解决卡通印花元素联动“像廉价塑料贴图”的问题？**
  - *选定方案*：在后端 Prompt 编译器中内置 **「潮玩盲盒材质与印花符号拆解指令（Pop-Art Vinyl & Motif Extraction）」**。
  - *原因*：明确指令模型从 `#Prod` 壳面插画中提取具体的故事母题与微小伴生符号（如十字闪星、行星环、云朵、帐篷、小花），强制规定衍生道具采用“细腻哑光潮玩手办材质 + 景深虚化层次”，并强制将底部信息胶囊与标题文字色号纳入联动范围，消除割裂感。

### 核心数据模型扩展

1. **产品原图视角角色与印花特征 (`ReferenceImageItem` 扩展)**：
   - `prodAngleRole?: 'hero_front' | 'open_case' | 'single_earbud' | 'detail_closeup' | 'multi_sku' | 'package_accessory'`：标识每张 `#Prod` 的拍摄视角角色，用于智能多图编排。
2. **印花 4 维主题联动配方 (`PrintThemeLinkageConfig`)**：
   - `themePalette: string`（主题三级色板：背景主色 + 展台辅色 + 强调色）
   - `themeStage: string`（联动潮玩底座描述）
   - `themeElements: string`（从印花提取的 2~3 个伴生悬浮符号）
   - `themeUiStyle: string`（标题字体色与底部卖点胶囊配色样式）
3. **主图转详情页基准锚点 (`ScreenTask` 扩展)**：
   - `sourceReplicaImageUrl?: string`：当从已生成的 `1:1` 主图延展为 `3:4` 或 `9:16` 详情屏时，保存原 `1:1` 成图数据，供生图接口作为纵向延展的基准参考图。
